# AI.STUDIO // Инженерные ИИ-решения для бизнеса

Высококонверсионный интерактивный лендинг с входным адаптивным квизом-конфигуратором и надежным Node.js Telegram-ботом на базе `Fastify 5` + `grammY 1` + `Prisma ORM` + `React 18` + `Tailwind CSS`.

Разработано в строгом соответствии с **PRD**, технической спецификацией (**SPEC**) и манифестом швейцарского индустриального инжиниринга (**DESIGN**).

---

## 🏗 Архитектура системы

```text
[Посетитель / Браузер]
   │  1. GET /api/v1/geo (Автоподстановка города жителя по Geo-IP)
   │  2. POST /api/v1/leads (Спецификация квиза + контакты жителя + UTM + Метаданные)
   ▼
[Fastify 5 API Server]
   ├── Zod-валидация DTO, защита Honeypot, Rate Limit (3 запроса/10 мин)
   ├── Обогащение: Geo-IP + парсинг User-Agent + генератор ID (#AI-YYYYMMDD-XXXX)
   ├── Гарантированное сохранение в Prisma ORM (SQLite / PostgreSQL)
   └── Notifier Service (экспоненциальный retry [2s, 5s, 15s])
          │
          ▼
   [grammY Telegram Bot]
          ├── Отправка HTML-карточки лида в рабочий чат менеджеров
          ├── Интерактивные Inline-кнопки:
          │     ├── «💬 Написать в Telegram» (прямой диалог с клиентом)
          │     ├── «✅ Взять в работу» (статус: 🔵 В работе @manager)
          │     ├── «🏁 Завершить» (статус: 🟢 Завершена)
          │     └── «🚫 Спам»
          └── Обработка Deep-link (/start lead_<id>) от клиента с экрана благодарности
```

## 🎨 Дизайн-система (Swiss Engineering Blueprint)

Проект полностью исключает визуальный «нейрослоп»:
- **Палитра:**
  - Базовый алебастр (`#F4F2EC`) — ощущение плотной чертежной бумаги 160 г/м²;
  - Светлые карточки (`#FAF9F5`) с тонкими графитовыми границами (`#D8D4C8`);
  - Глубокий графитовый текст (`#141413`) с контрастом > 15:1;
  - Сигнальный индустриальный оранжевый (`#E04420`) для ключевых CTA;
  - Чертежный кобальт (`#1A4B8C`) для технических тегов и моста в Telegram;
  - Темная графитовая приборная панель для кейсов и футера.
- **Типографика:**
  - `Golos Text` — безупречная кириллица для заголовков и интерфейса;
  - `IBM Plex Serif` (Italic) — редакционный акцент в ключевых фразах УТП;
  - `IBM Plex Mono` (`tabular-nums`) — моноширинные индексы, задержки, бюджеты и живой тикет.
- **Интерактивные элементы:**
  - Архитектурная выдвижная панель квиза (Side Sheet 760px на десктопе, 100dvh на мобильных);
  - Живой инженерный тикет, обновляющийся в реальном времени;
  - Интерактивная векторная схема пайплайна в Hero-секции;
  - Асимметричная 6-колоночная бенто-сетка услуг без «висящих» карточек;
  - Таймер входного окна (4 сек) с защитой от назойливости (24ч `localStorage`).

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

В папке `backend/` скопируйте `.env.example` в `.env`:

```bash
cd backend
cp .env.example .env
```

Параметры `.env`:
- `PORT=3000` — порт Fastify сервера
- `DATABASE_URL="file:./dev.db"` — путь к SQLite базе (или строка подключения к PostgreSQL)
- `TELEGRAM_BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather)
- `TELEGRAM_ADMIN_CHAT_ID` — ID группы или чата, куда приходят карточки лидов
- `TELEGRAM_BOT_USERNAME` — юзернейм вашего бота (для ссылок deep-link)

> **💡 Подсказка:** Если `TELEGRAM_BOT_TOKEN` не указан или оставлен по умолчанию, сервер работает в **Dev Mock Mode** — выводит красивую карточку со всеми кнопками и полями прямо в терминал, что позволяет полноценно тестировать лендинг без регистрации бота!

### 3. Инициализация базы данных

```bash
cd backend
npx prisma db push
```

### 4. Запуск в режиме разработки

В корне проекта:

```bash
# Запуск бэкенда Fastify + бота (порт 3000):
npm run dev:backend

# В отдельном терминале запуск Vite React фронтенда (порт 5173):
npm run dev:frontend
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

## 📡 REST API Контракты

### `GET /api/v1/geo`
Возвращает геолокацию посетителя по IP для умной автоподстановки поля «Город / Район проживания»:
```json
{
  "country": "Узбекистан",
  "region": "Ташкент",
  "city": "Ташкент",
  "timezone": "Asia/Tashkent",
  "suggested_location": "Ташкент"
}
```

### `POST /api/v1/leads`
Прием заявки с квиза.
```json
{
  "quiz_source": "entry_popup",
  "service_focus": {
    "service_code": "chatbot",
    "primary_service": "ИИ-чат-боты и голосовые продавцы",
    "service_details": ["Telegram", "Instagram Direct", "Продавать и собирать заявки"],
    "industry": "Интернет-магазин / Маркетплейсы",
    "timeline": "В течение 1 месяца",
    "budget": "$500 – $1 500"
  },
  "resident_info": {
    "name": "Алишер Каримов",
    "city_input": "Ташкент, Мирзо-Улугбекский район",
    "preferred_channel": "Telegram",
    "phone": "+998901234567",
    "telegram_username": "@alisher_k",
    "comment": "Нужен бот для каталога товаров"
  },
  "consent_accepted": true,
  "security": {
    "honeypot": ""
  }
}
```

Ответ `201 Created`:
```json
{
  "success": true,
  "lead_id": "AI-20261119-4821",
  "bot_deep_link": "https://t.me/YourAiServicesBot?start=lead_AI-20261119-4821"
}
```

### `GET /api/v1/health`
Проверка состояния сервиса и доступности БД.
